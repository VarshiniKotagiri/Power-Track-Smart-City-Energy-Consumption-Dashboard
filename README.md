# PowerTrack: Smart City Energy Consumption Dashboard

## Overview
PowerTrack is a web-based Smart City Energy Monitoring Dashboard developed using HTML, CSS, and JavaScript. The system provides real-time visualization and analysis of energy consumption across residential, commercial, industrial, and public sectors.

## Features
- Real-time energy monitoring
- Zone-wise energy analysis
- Peak load visualization
- Interactive charts and graphs
- KPI tracking dashboard
- Responsive user interface

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Chart.js

## Dashboard Metrics
- Total Energy Consumption
- Peak Load
- Load Factor
- Peak Usage Time

## Future Enhancements
- IoT integration
- AI-based energy prediction
- Cloud database connectivity
